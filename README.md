# C# Conditionals Practice Project 🧠💻

This project is a comprehensive C# console application designed to practice and demonstrate the implementation of conditional control structures (`if-else`, `switch`). It features a collection of real-world logic exercises managed through an interactive menu.

## 🚀 Key Features

- **Interactive Menu System**: Easily navigate through different exercises without restarting the application.
- **Robust Input Validation**: Implements `TryParse` logic to handle invalid user inputs and prevent application crashes.
- **Clean Code Architecture**: Logic organized into modular static methods for better readability and maintenance.
- **Formatted Console Output**: Uses colors and clear layouts to improve user experience.

## 📋 Included Exercises

1.  **Event Admission**: Checks age and registration status for event entry. 🎟️
2.  **University Scholarships**: Calculates eligibility based on distance, income, and social stratum. 🎓
3.  **Speed Control**: Monitors vehicle speed and calculates fines for exceeding limits. 🏎️🚦
4.  **Subsidy Program**: Determines social subsidy amounts based on age brackets. 💰
5.  **Banking Services**: Simulates a banking queue system for various services. 🏦
6.  **Liquor Store Simulation**: A retail system to select products, quantities, and calculate total costs. 🍾🥃

## 🛠️ Built With

- **Language**: C#
- **Platform**: .NET Console Application
- **IDE**: Visual Studio / VS Code

## ⚙️ How to Run

1. Clone this repository.
2. Open the solution file `Condicionales.sln` in Visual Studio.
3. Build and Run the project (F5).
4. Follow the on-screen menu instructions to explore the different exercises.
